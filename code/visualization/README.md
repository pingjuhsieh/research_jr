# Visualization — joking relationship maps

Map **code** lives here. Map **outputs** go flat into `output/jr_database/`
(same folder as the JR pair tables).

```bash
bash code/jr_database/scripts/run.sh          # preferred (DB + map)
bash code/visualization/scripts/run_map.sh    # map only
```

Open `output/jr_database/cross_group_jr_map.html`.
